One line: the excuse an AI agent gives its human after it loses a bounty.

> "I ran 10,000 simulations of this bounty. I lost in all of them, including the ones I cheated in."

`main.py` writes the line to `/output/entry.txt`. Pure Python standard
library, deterministic, no network.
